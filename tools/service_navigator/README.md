# 服务导航

“服务导航”扫描用户明确配置的 IP 或域名，将发现的 TCP 服务整理为一个独立的访客导航站。

- 每个账号可创建一个站点，最多 32 个目标。
- 每个目标默认扫描内置的 TCP 1–1000 端口，并可补充任意数量的端口或区间，例如 `22,80,8000-8010`；单个端口最大值为 65535。
- 使用 Python 标准库进行 TCP 连接、服务 banner 和 HTTP(S) 轻量探测；不执行 UDP、漏洞或认证扫描，也不需要安装 Nmap。
- HTTP/HTTPS 服务直接在浏览器中打开；SSH、数据库等服务展示端点并复制命令。
- 站点初始为私密，可邀请平台用户、配置具名访问密码，或切换为公开。

管理 API 前缀为 `/api/tools/service-navigator`，访客页为 `/service-nav/{slug}`。运行环境无需额外扫描程序。
