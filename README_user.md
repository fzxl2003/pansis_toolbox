# Pansis Toolbox — 用户指南

Pansis Toolbox 是一个插件式工具箱平台，提供可扩展的工具集来辅助日常运维和开发工作。所有工具统一在 Web 界面中访问，无需安装额外的客户端。

---

## 快速开始

### 启动服务

```bash
# 同时启动后端和前端（推荐）
python3 scripts/dev.py

# 或分别启动
# 后端（API 端口 8000）
npm run backend

# 前端（开发服务器端口 5173）
npm run frontend
```

启动后，浏览器访问 **http://localhost:5173** 即可打开主界面。

### 默认管理员账号

| 用户名    | 密码         | 角色       |
| --------- | ------------ | ---------- |
| `admin` | `admin123` | 超级管理员 |

首次启动时系统会自动创建该账号，建议登录后立即修改密码。

---

## 界面导航

左侧边栏包含两个主要导航项：

- **首页** — 展示已启用的工具卡片和仪表板小组件
- **设置** — 个人密码修改、数据清理；管理员可管理用户、工具权限、邮件配置

工具卡片点击可直接进入对应工具页面。

## 用户体系

### 角色

| 角色                 | 权限                                                                     |
| -------------------- | ------------------------------------------------------------------------ |
| **超级管理员** | `admin`（用户名）账号，拥有全部权限，可以创建/删除管理员账号、调整角色 |
| **管理员**     | 可管理普通用户、配置工具可见性、清理数据、配置邮件                       |
| **普通用户**   | 使用工具有权限的工具、管理个人密码和数据                                 |
| **未登录用户** | 仅能使用设为「全局公开」的工具                                           |

### 常用操作

- **修改密码**：设置 → 个人 → 修改密码
- **管理员添加用户**：设置 → 用户管理 → 添加用户
- **管理员重置用户密码**：设置 → 用户管理 → 用户列表 → 输入新密码 → 重置

## 工具列表

当前内置了以下工具，后续可通过插件机制添加更多。

### 文本清洗

去除文本中的多余空白、空行，支持大小写转换。在文本框中输入内容，勾选处理选项，点击"清洗文本"即可。

### 服务器监控看板

通过 SSH 监控多台服务器的 CPU、CUDA GPU、内存、硬盘挂载点和目录用量。

- 管理员可以维护默认服务器列表、SSH 账号密码
- 普通用户可以添加仅自己可见的私有服务器
- 历史采样默认每 30 秒一次，保留 30 天

### 网址导航

个人化多入口网址导航工具。每个登录用户拥有独立的链接管理。

- 支持为同一服务配置多个入口（内网/公网），自动探测可用性并按优先级或延迟选择
- 普通用户可以增删改自己的链接
- 管理员可以维护默认链接模板

### 备忘录 Demo

个人备忘录工具，支持上传 `.txt` 文件保存和管理。

- 数据存储在个人目录中，其他用户不可见
- 支持上传、列表查看、详情查看和删除

## 管理员功能

### 工具可见性控制

设置 → 工具可见性

每个工具可以设为：

- **全局公开** — 任何未登录用户也能访问
- **按用户授权** — 仅限指定的已登录用户使用

### 数据清理

设置 → 工具数据清理

管理员可以按工具、分类、时间范围精确删除数据，支持：

- 查看各工具存储占用（饼图可视化）
- 按用户维度清理
- 按日期范围筛选
- 删除前预览影响的行数

普通用户可以在「个人」标签页中清除自己的数据。

### 邮件配置

设置 → 邮件配置

平台统一的 SMTP 邮件发送配置，所有工具共享。

- 支持 SSL 加密（端口 465）
- 密码加密存储
- 保存后可发送测试邮件验证

```text
storage/
├── data/                     # 平台共享数据
│   └── tools/                #   工具共享文件
├── data/platform.db          # 平台主数据库（用户、会话、设置）
├── user_data/                # 用户数据
│   └── {user_id}/
│       └── tools/
│           └── {tool_id}/    # 各用户在各工具下的数据
│               └── data.db   #   SQLite 数据库
└── widget_layout.json        # 仪表板布局
```

## 常见问题

**Q: 如何创建新工具？**

项目支持插件式工具开发。在项目根目录下运行：

```bash
python3 scripts/create_tool.py my_tool_id
```

这会自动生成工具骨架代码（manifest.json、后端路由、前端组件），然后可按需修改。

创建后需要运行以下命令更新前端注册表：

```bash
npm run generate:tools
```

验证工具配置：

```bash
npm run check:tools
```

**Q: 忘记管理员密码？**

直接修改 `pyproject.toml` 同级的 `.env` 文件（如果没有则新建），设置：

```env
DEFAULT_ADMIN_PASSWORD=newpassword
```

然后重启服务，系统会自动更新密码。

**Q: 服务端口被占用？**

后端默认使用 8000 端口，前端使用 5173 端口。可以通过环境变量或 `.env` 文件覆盖配置。

**Q: 工具报 "Tool frontend not installed"？**

通常是因为新增了工具后没有重新生成前端注册表，运行 `npm run generate:tools` 即可。
